# 02 · Alcance

Última actualización: 2026-10-01 · Persona Ficticia

## Objetivo del proyecto

Un portal único de reservas de grupos para los hoteles de Hotelera Demo, que sustituya las hojas de cálculo actuales.

## Qué entra

- Alta y consulta de reservas de grupos.
- Calendario de disponibilidad por hotel.
- Informe semanal de ocupación en Power BI.
- Hasta 3 usuarios por hotel.

## Qué no entra

- Integración con el sistema de facturación SAP (evolutivo para una fase 2).
- Aplicación móvil.
- Migración de reservas anteriores a 2025.

## Supuestos

- El cliente entrega el catálogo de hoteles antes del 20 de octubre.
- El acceso al entorno de pruebas del cliente está disponible desde el kick off.
